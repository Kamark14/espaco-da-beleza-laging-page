# Espaço da Beleza — Landing Page

Landing page responsiva criada como demonstração comercial para o Espaço da Beleza, Pirituba/SP.

## Estrutura
- `index.html` — estrutura e conteúdo
- `styles.css` — UI/UX, responsividade e animações
- `script.js` — menu mobile, scroll reveal, barra de progresso e galeria/lightbox
- `assets/` — imagens derivadas das imagens fornecidas na conversa

## Como abrir
Abra `index.html` no navegador. Para publicar, envie a pasta para uma hospedagem estática como Vercel, Netlify ou GitHub Pages.

## Observação comercial
Os textos e dados devem ser confirmados com o estabelecimento antes da publicação oficial, especialmente horários, serviços, e-mail e links das redes sociais.
